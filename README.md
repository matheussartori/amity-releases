# Amity — desktop builds

Serverless voice, video and text chat over Nostr. **[amity.chat](https://amity.chat)** · web app: **[app.amity.chat](https://app.amity.chat)**

This repository only hosts the desktop installers. Grab the newest one:

| Platform | Download |
|---|---|
| macOS (Apple Silicon + Intel) | [Amity-mac.dmg](https://github.com/matheussartori/amity-releases/releases/latest/download/Amity-mac.dmg) |
| Windows | [Amity-Setup.exe](https://github.com/matheussartori/amity-releases/releases/latest/download/Amity-Setup.exe) |
| Linux | [AppImage](https://github.com/matheussartori/amity-releases/releases/latest/download/Amity-linux.AppImage) · [.deb](https://github.com/matheussartori/amity-releases/releases/latest/download/Amity-linux.deb) |

Installed apps update themselves.

**macOS first launch:** the app isn't notarized yet — open it once, then allow it in System Settings → Privacy & Security → "Open Anyway".
